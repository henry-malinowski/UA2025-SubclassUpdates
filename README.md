# UA2025-SubclassUpdates

A Foundry implementation of the UA2025-SubclassUpdates document released on D&amp;DBeyond

- Full subclass integration in the FoundryVTT compendium system
- Stylized subclass icons

- **Path of the Storm Herald** (Barbarian)

# Installation Instructions

To install and use the UA2025-SubclassUpdates module for Foundry Virtual Tabletop, simply paste the following URL into the **Install Module** dialog on the Setup menu of the application.

`https://github.com/henry-malinowski/UA2025-SubclassUpdates/releases/latest/download/module.json`

If you wish to manually install the module, you must clone or extract it into the `Data/modules/UA2025-SubclassUpdates` folder. You may do this by cloning the repository or downloading a zip archive from the [Releases Page](https://github.com/henry-malinowski/UA2025-SubclassUpdates/releases).
